# 📚 Engineering Philosophy

```c
int main(void)
{
    while (learning)
    {
        build();
        break_things();
        debug();
        understand();
        improve();
    }

    return 0;
}
```

I value:

* **Understanding over memorization**
* **Building over endlessly watching tutorials**
* **Fundamentals over hype**
* **Documentation over guessing**
* **Debugging over blaming the compiler**
* **Simple solutions over unnecessary complexity**

And probably the most important one:

> **If I can't explain it, I don't understand it yet.**
